# Комп'ютерний практикум №3. Скінченні поля характеристики 2 (поліноміальний базис)

Реалізація арифметики у полі Галуа GF(2^281) мовою C++ (варіант 8: m = 281, p(x) = x^281 + x^9 + x^4 + x + 1).

## Архітектура представлення елементів

Елемент поля — це многочлен степеня менше 281 над GF(2), що зберігається як бітовий вектор у масиві з 9 слів по 32 біти (`uint32_t words[9]`) у форматі little-endian. Біт з номером i відповідає коефіцієнту при x^i.

У старшому слові використовуються лише 25 біт (`TOP_MASK = 0x01FFFFFF`). Після кожної операції старші біти занулюються (`mask_top()`), тому порівняння елементів (`==`) виконується просто за словами.

Добуток двох елементів спочатку обчислюється в проміжному буфері з 18 слів (576 біт), після чого виконується редукція за многочленом p(x).

## Операції (клас `FieldElement281`)

1. Константи: `zero()` — нейтральний елемент за додаванням, `one()` — за множенням.
2. Додавання (`add`, `operator+`) — побітовий XOR слів.
3. Множення (`multiply`, `operator*`) — побітове множення без переносів (shift-and-XOR) з подальшою редукцією за p(x).
4. Піднесення до квадрата (`square`).
5. Слід елемента (`trace`): Tr(a) = a + a^2 + a^4 + … + a^(2^(m-1)), результат 0 або 1.
6. Піднесення до степеня (`pow`, `pow_uint`) — двійковий алгоритм «квадрат і множ».
7. Обернений елемент (`inverse`): a^(-1) = a^(2^m − 2), обчислюється за схемою Горнера; для нуля кидає `std::domain_error`.
8. Перетворення рядків: `to_string_bin`, `from_string_bin` (кидає `std::invalid_argument` і `std::out_of_range`), `from_string_hex`, `print_hex`.

| Файл | Призначення |

## Збірка та запуск

```bash
g++ -std=c++17 -O2 -Wall -Wextra main.cpp -o main
g++ -std=c++17 -O2 -Wall -Wextra test_field.cpp -o test_field
g++ -std=c++17 -O2 -Wall -Wextra bench.cpp -o bench

./main
./test_field
./bench
```
